КАК ПОЛУЧИТЬ УСТАНОВЩИК MBA — ПОШАГОВО
=======================================
Всё делается в браузере. Ничего устанавливать на компьютер не нужно.
Времени: 10 минут вашего участия + 20 минут ожидания сборки.


ШАГ 1. РЕГИСТРАЦИЯ НА GITHUB (если аккаунта нет)
-------------------------------------------------
1. Откройте github.com -> кнопка "Sign up" справа вверху.
2. Введите почту, придумайте пароль и имя пользователя.
3. Подтвердите почту по письму.
Аккаунт бесплатный, сборка тоже бесплатная.


ШАГ 2. СОЗДАНИЕ РЕПОЗИТОРИЯ
----------------------------
1. Справа вверху нажмите "+" -> "New repository".
2. Repository name: mba-browser (любое латиницей, без пробелов).
3. Выберите "Private" — код будет виден только вам.
4. Нажмите "Create repository".
Откроется пустая страница с подсказками — оставьте её открытой.


ШАГ 3. ЗАГРУЗКА ФАЙЛОВ ПРИЛОЖЕНИЯ
----------------------------------
1. Скачайте архив с сайта (кнопка "Приложение для ПК" в меню слева).
2. Распакуйте его. Внутри будет папка mba со всем содержимым.
3. На странице репозитория нажмите "uploading an existing file"
   (или "Add file" -> "Upload files").
4. Откройте папку mba, выделите ВСЁ внутри (Ctrl+A на Windows,
   Cmd+A на Mac) и перетащите в окно браузера.
   ВАЖНО: тащите содержимое папки mba, а не саму папку.
5. Дождитесь, пока все файлы загрузятся (появится список).
6. Внизу нажмите "Commit changes".


ШАГ 4. ПРОВЕРКА СЦЕНАРИЯ СБОРКИ
--------------------------------
Посмотрите список файлов в репозитории. Есть ли папка .github?

ЕСЛИ ЕСТЬ — переходите к шагу 5.

ЕСЛИ НЕТ (частый случай, папка скрытая и не перетаскивается):
   1. "Add file" -> "Create new file".
   2. В поле имени вставьте ровно:  .github/workflows/build.yml
      Косые черты сами создадут папки.
   3. Откройте файл build-workflow-копия.yml из архива в Блокноте,
      скопируйте всё содержимое, вставьте в окно на GitHub.
   4. "Commit changes".


ШАГ 5. ЗАПУСК СБОРКИ
---------------------
1. Вверху страницы репозитория откройте вкладку "Actions".
2. Если появится предложение включить Actions — нажмите
   "I understand my workflows, go ahead and enable them".
3. Слева выберите "Сборка установщиков MBA".
4. Справа нажмите серую кнопку "Run workflow" -> зелёную "Run workflow".
5. Через несколько секунд обновите страницу — появится жёлтый кружок,
   значит сборка пошла.

Сборка идёт 15-25 минут: скачивается ядро браузера (~150 МБ)
и упаковывается в установщик. Можно закрыть вкладку и вернуться позже.


ШАГ 6. СКАЧИВАНИЕ ГОТОВЫХ УСТАНОВЩИКОВ
---------------------------------------
1. Когда кружки станут зелёными галочками — сборка готова.
2. Нажмите на строку сборки, чтобы открыть её.
3. Прокрутите вниз до раздела "Artifacts".
4. Скачайте два архива:
      MBA-installer-windows  ->  внутри MBA-Setup-1.0.0.exe
      MBA-installer-macos    ->  внутри MBA-1.0.0-arm64.dmg
                                 и MBA-1.0.0-x64.dmg
5. Распакуйте — это и есть готовые установщики.

Какой dmg нужен для Mac:
   arm64 — для Mac на Apple M1/M2/M3 (все с 2020 года)
   x64   — для старых Mac на процессорах Intel


ШАГ 7. УСТАНОВКА
-----------------
Windows:
   Запустите MBA-Setup-1.0.0.exe.
   Появится синее окно "Windows защитила ваш компьютер" — это нормально
   для программ без платного сертификата.
   Нажмите "Подробнее" -> "Выполнить в любом случае".

macOS:
   Откройте .dmg, перетащите MBA в папку "Программы".
   При первом запуске система скажет "неизвестный разработчик".
   Закройте окно, зайдите в "Программы", нажмите на MBA
   ПРАВОЙ кнопкой -> "Открыть" -> "Открыть".
   Дальше приложение будет запускаться обычным двойным кликом.


ЕСЛИ СБОРКА УПАЛА (красный крестик)
------------------------------------
1. Откройте сборку и посмотрите, на каком шаге ошибка.
2. Чаще всего это сетевой сбой при скачивании ядра браузера —
   просто запустите сборку заново кнопкой "Re-run jobs".
3. Если ошибка на шаге "Проверка, что ядро браузера на месте" —
   тоже перезапустите, обычно помогает со второго раза.


ВЫПУСК СЛЕДУЮЩИХ ВЕРСИЙ
------------------------
1. В репозитории откройте package.json, нажмите карандаш.
2. Замените "version": "1.0.0" на "1.0.1" -> "Commit changes".
3. Actions -> Run workflow -> дождитесь -> скачайте установщики.
4. Загрузите их на сайт через форму публикации версий.

Все установленные приложения увидят обновление сами: скачают
и предложат установить. Профили и куки при этом сохранятся.
