ОШИБКА "lookup github.com ... connection refused"
==================================================
Что произошло: сборщику нужно скачать движок Electron с github.com,
а ваш Mac не может открыть этот адрес. Проблема сетевая, не в коде.

Ниже три способа. Начните с первого — он срабатывает чаще всего.


СПОСОБ 1. ЗЕРКАЛО ЗАГРУЗКИ (без VPN, 1 минута)
-----------------------------------------------
Скачиваем движок с китайского зеркала вместо github.com.

В Терминале, находясь в папке mba, введите одной строкой:

export ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/

Затем повторите сборку:

npm run build:mac

Если снова ошибка — попробуйте второе зеркало:

export ELECTRON_MIRROR=https://mirrors.huaweicloud.com/electron/


СПОСОБ 2. СМЕНИТЬ DNS (помогает, если провайдер блокирует)
-----------------------------------------------------------
1. Меню Apple -> "Системные настройки"
2. "Сеть" -> ваше подключение (Wi-Fi) -> "Подробнее"
3. Вкладка "DNS" -> кнопка "+" внизу списка
4. Добавьте два адреса, каждый отдельной строкой:
       1.1.1.1
       8.8.8.8
5. "ОК" -> "Применить"
6. В Терминале проверьте:
       ping -c 2 github.com
   Если пошли ответы — повторите npm run build:mac


СПОСОБ 3. VPN
--------------
Включите любой VPN и повторите:
    npm run build:mac
После успешной сборки VPN можно выключить — движок скачивается
один раз и остаётся в кэше.


ЕСЛИ НУЖЕН ТОЛЬКО ВАШ MAC (сборка вдвое быстрее)
-------------------------------------------------
По умолчанию собираются обе версии — для Apple M-чипов и для Intel.
Если Intel-версия не нужна, соберите только под свой процессор:

    npx electron-builder --mac --arm64

(для старого Mac на Intel вместо --arm64 напишите --x64)

Так скачается только один движок вместо двух.


ПРОВЕРКА, ЧТО ПОМОГЛО
----------------------
Успешная сборка заканчивается строками вида:
    • building        target=DMG arch=arm64
    • building        target=DMG arch=x64

Готовые файлы:
    open dist
