СБОРКА ПРИЛОЖЕНИЯ НА СВОЁМ MAC
===============================
Так вы получите только .dmg для macOS.
Установщик .exe для Windows на Mac собрать нельзя — для него
используйте сборку через GitHub (см. ИНСТРУКЦИЯ.txt).

Времени: 5 минут работы + 10-15 минут ожидания.


ШАГ 1. УСТАНОВИТЬ NODE.JS
--------------------------
1. Откройте nodejs.org
2. Скачайте версию с пометкой "LTS" (слева, зелёная кнопка).
3. Запустите скачанный .pkg и нажимайте "Продолжить" до конца.

Проверка: откройте Терминал (Cmd+Пробел, наберите "Терминал")
и введите:
    node -v
Должно появиться что-то вроде v20.11.0


ШАГ 2. ОТКРЫТЬ ПАПКУ ПРИЛОЖЕНИЯ В ТЕРМИНАЛЕ
--------------------------------------------
Способ простой:
1. Наберите в Терминале:  cd 
   (именно cd и ПРОБЕЛ после него, Enter пока не нажимайте)
2. Перетащите папку mba из Finder прямо в окно Терминала —
   путь подставится сам.
3. Нажмите Enter.

Проверка: введите  ls
Должны увидеть: main.js  package.json  core  app  scripts


ШАГ 3. УСТАНОВИТЬ ЗАВИСИМОСТИ
------------------------------
Введите:
    npm install

Идёт 5-10 минут. Скачивается ядро браузера, около 150 МБ.
В конце появится строка "Ядро браузера установлено внутрь проекта"
и "added N packages".

Если увидите предупреждения (warn) — это нормально, не ошибки.


ШАГ 4. СОБРАТЬ УСТАНОВЩИК
--------------------------
Введите:
    npm run build:mac

Идёт 5-15 минут. В конце появится строка вида
"building target=DMG arch=arm64" и "building target=DMG arch=x64".

Готовые файлы лежат в папке dist внутри папки mba:
    MBA-1.0.0-arm64.dmg   — для Mac на Apple M1/M2/M3/M4
    MBA-1.0.0-x64.dmg     — для старых Mac на Intel

Открыть папку с результатом:
    open dist


ШАГ 5. УСТАНОВИТЬ
------------------
1. Двойной клик по нужному .dmg
2. Перетащите значок MBA в папку "Программы"
3. ПЕРВЫЙ запуск: откройте "Программы", нажмите на MBA
   ПРАВОЙ кнопкой -> "Открыть" -> ещё раз "Открыть"
   (обычный двойной клик в первый раз выдаст "неизвестный
   разработчик" без кнопки запуска)
4. Дальше приложение открывается обычным способом.


ЧАСТЫЕ ОШИБКИ
--------------
"command not found: npm"
    Node.js не установлен или Терминал открыт до установки.
    Закройте Терминал, откройте заново.

"No such file or directory: package.json"
    Вы не в той папке. Повторите шаг 2 — важно попасть
    именно в папку mba, где лежит package.json.

"EACCES: permission denied"
    Папка лежит в защищённом месте. Перенесите mba
    в Документы и повторите с шага 2.

Сборка идёт очень долго на шаге npm install
    Это нормально: качается ядро браузера 150 МБ.
    Проверьте интернет, при обрыве запустите npm install заново.

"Cannot find module 'electron'"
    Не прошёл npm install. Выполните его ещё раз.


КАКОЙ DMG КОМУ
---------------
Не знаете, какой у вас Mac?
Меню Apple -> "Об этом Mac":
    Чип Apple M1/M2/M3/M4  -> arm64
    Процессор Intel        -> x64
